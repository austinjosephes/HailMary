# അമ്മയോടൊപ്പം
### 100,000 Hail Marys Devotional Offering Campaign
**Presented by CLC Velappaya**

---

## 🌟 About the Project
**അമ്മയോടൊപ്പം** is a devotional web application created for **CLC Velappaya** to track and dedicate a collective spiritual offering of **100,000 Hail Marys** in honor of Our Blessed Mother Mary.

The website features an elegant **blue and white** Marian design with an English user interface, retaining the Malayalam title **അമ്മയോടൊപ്പം**, and a direct number input system for submitting prayers.

---

## ✨ Features

- 🎯 **100,000 Target Dashboard**:
  - Live digital counter tracking progress toward 100,000 Hail Marys.
  - Real-time progress bar with percentage and remaining prayer count.
  - Spiritual milestones (10K, 25K, 50K, 100K) with celebratory confetti.

- ✍️ **Direct Prayer Entry (Number Input)**:
  - Prominent numeric input field where users enter the exact number of Hail Marys prayed (e.g., 10, 50, 100, etc.).
  - Plus (`+`) and Minus (`-`) stepper buttons.
  - Quick preset chips (`+1`, `+10`, `+50`, `+100`, `+150`) for quick selection.
  - "Submit to Offering" button with responsive feedback.

- 🔔 **Liturgical Church Bell Chimes**:
  - Pure Web Audio API chime upon submission and celebratory arpeggio for milestones.
  - Sound on/off toggle.
  - Haptic feedback on mobile devices.

- 📖 **Today's Rosary Mysteries**:
  - Automatically identifies the day of the week and displays the corresponding mystery meditations in English:
    - **Monday & Saturday:** Joyful Mysteries
    - **Thursday:** Luminous Mysteries
    - **Tuesday & Friday:** Sorrowful Mysteries
    - **Wednesday & Sunday:** Glorious Mysteries

- 📜 **Prayer Guide Modal**:
  - Complete Hail Mary prayer text in English (with Malayalam reference).
  - Fatima prayer & Glory Be.

- 📲 **WhatsApp Progress Sharing**:
  - One-tap button to share current campaign progress and milestone status to parish and family WhatsApp groups.

- 💾 **Local Storage & Control**:
  - Saves your progress in browser `localStorage`.
  - Undo button to correct accidental entries.
  - Safe adjust/reset total modal.
